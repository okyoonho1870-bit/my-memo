# my-memo

## 강의 슬라이드 (`lectures/`)

- `lectures/index.html` — 강의 목록(메인) 페이지: 검색, 완료/준비중 필터, 발표 시작·발표자 모드 바로가기
- `lectures/lectures.js` — 강의 목록 데이터. 새 강의는 HTML 파일을 `lectures/`에 넣고 여기에 한 항목을 추가
- 슬라이드 단축키: ← → 넘김 · F 전체화면 · P 발표자 창 열기 · H 목록
- 발표자 창(별도 창, 확장 모니터용): 현재·다음 슬라이드, 원고, 타이머(T 시작·정지, R 리셋), +/− 원고 글자 크기. 어느 창에서 넘겨도 두 창이 함께 넘어감
